# Lessons

- When importing a requested skill collection, include its full modules and shared dependencies. A short custom router is not a complete import. Adapt the entry point and paths without replacing the source material with summaries.
- A shared coding workflow should compose language specialists instead of duplicating them. Treat immutability, coverage, function size, and research depth as context-dependent engineering decisions rather than universal quotas.
- Keep repository-history operations and commit-message style as separate skills. Route to them from the coding lifecycle only when a task actually changes Git state.
- When a skill depends on host tools, pin the package that provides them and verify that the runtime configuration includes the same package set.
- When a pinned extension raises its Node.js engine floor, update and validate both the package manifest and the install documentation.
